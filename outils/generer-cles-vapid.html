Générer les clés de notification (VAPID)

Cette page crée une paire de clés directement dans votre navigateur. Rien n'est envoyé sur Internet. Ouvrez ce fichier sur votre ordinateur (double-clic), puis cliquez sur le bouton.

Clé publique — à coller dans app/js/config.js (vapidPublicKey) et dans le secret GitHub VAPID_PUBLIC_KEY
Clé privée — à coller seulement dans le secret GitHub VAPID_PRIVATE_KEY

Ne mettez jamais la clé privée dans le code de l'application. Gardez-la secrète.
